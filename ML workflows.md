<h2>Introduction to Machine Learning Engineering</h2>
<p>Technology is about people. A machine learning engineer is a person on our team who is most responsible for taking the work products from other data professionals like data scientists and data engineers and making them production-ready according to the standards of the rest of the engineering organization.</p>
<p>As a MLE, you are concerned with things like:</p>
<ul>
  <li>Deploying APIs</li>
  <li>Automating workflows</li>
  <li>Monitoring</li>
  <li>ML specific concerns like bias</li>
</ul>
<h5>New Terms</h5>
<ul>
  <li>Monitoring: gathering data about the performance and behavior of systems. These can often be logs, or statistics about the system.</li>
  <li>Deploying: delivering a new resource, or updating to a new version of a resource.</li>
  <li>Bias: model behavior that disadvantages a class of users.</li>
  <li>Model bias: a data science term used to describe how well the model matches its training inputs.</li>
  <li>API: stands for Application Programming Interface. This enables applications to interact with machine learning models easily and securely.</li>
</ul>

<h3>AI: Foundation and subsequent winters</h3>
<ul>
  <li>
    Initial research:
    <ul>
      <li>1950: Computing Machinery and Intelligence, Alan Turing</li>
      <li>1958: Frank Rosenblatt develops the first Perceptron at Cornell</li>
    </ul>
  </li>
  <li>
    First AI Winter (1973-1981): Dashed Expectations
    <ul>
      <li>1973: Lighthill Report</li>
      <li>1980: Proliferation of expert systems begins</li>
    </ul>
  </li>
  <li>
    Second AI Winter (1987-1997):
    <ul>
      <li>1987: Collapse of the expert systems market</li>
      <li>1997: IBM’s Deep Blue defeats Gary Kasparov</li>
    </ul>
  </li>
</ul>
<h3>Installation Period: Setting the Stage for MLE</h3>
<ul>
  <li>
    Dawn of Big Data:
    <ul>
      <li>2004: MapReduce: Simplified Data Processing on Large Clusters, Jeffrey Dean and Sanjay Ghemawat</li>
      <li>2006: AWS launches its first service to the public: Amazon Simple Storage Service (S3)</li>
    </ul>
  </li>
  <li>
    Data-centric approaches to AI:
    <ul>
      <li>2006: Fei-Fei Li begins work on ImageNet</li>
      <li>2012: AlexNet clears the field in computer vision</li>
    </ul>
  </li>
  <li>
    Serverless Movement begin emerging
    <ul>
      <li>2014: AWS launches Lambda (and the Serverless Movement)</li>
      <li>2016: AWS launches Step Functions</li>
    </ul>
  </li>
  <li>2015: Hidden Technical Debt in Machine Learning Systems, Sculley, et al</li>
</ul>
